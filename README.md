## What This Project Does

This repository contains the practical implementation of a DevSecOps framework developed as part of a Bachelor's thesis. It demonstrates how security scanning tools can be automatically integrated into a CI/CD pipeline using GitHub Actions.

The pipeline runs automatically on every code push and performs:

1. **SonarCloud** — Static Application Security Testing (SAST): scans source code for vulnerabilities
2. **OWASP Dependency-Check** — Software Composition Analysis (SCA): checks third-party libraries for known CVEs
3. **Trivy** — Container Image Scanning: scans the Docker image for OS and package vulnerabilities

## Demo Application

The Flask application (`app.py`) contains **intentionally introduced vulnerabilities** for research evaluation purposes. This is a controlled research environment — these vulnerabilities exist so that the security tools have something real to detect.

| Route | Vulnerability | CWE |
|-------|--------------|-----|
| `/search` | Unsanitized user input reflected in response (XSS) | CWE-79 |
| `/fetch` | User-supplied URL passed to HTTP request (SSRF) | CWE-918 |
| `/admin` | Hardcoded credentials exposed in response | CWE-200 |
| startup | Debug mode on, bound to all interfaces | CWE-605 |

**⚠️ Do not deploy this application in any real environment.**

## Pipeline Setup

To run this pipeline in your own GitHub repository:

1. Fork or clone this repository
2. Go to **Settings → Secrets and variables → Actions**
3. Add a secret named `SONAR_TOKEN` with your SonarCloud API token
4. Push any change to the `main` branch to trigger the pipeline

Pipeline results (scan reports) are saved as GitHub Actions artifacts after each run.
